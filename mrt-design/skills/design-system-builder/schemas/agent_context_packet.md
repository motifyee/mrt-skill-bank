# Agent Context Packet

This file has been split into focused documents for maintainability.

**Validation and defaults:**
- `schemas/packet_validation.md` -- Pre-dispatch checklist, cross-validation logic (character_rules vs component_style_contract), default fallbacks, contrast validation, and decision log guidelines

**Agent slicing:**
- `schemas/packet_slicing.md` -- Per-agent slicing table, compact packet format, globalization notes, and the compact packet example

**Full example packets:**
- `references/packet_examples.md` -- Complete worked example (Velocity developer tool) showing every field populated
